Discord Rich Presence для Яндекс Музыки. Показывает, что ты слушаешь прямо сейчас, а когда музыки нет, крутит обычные статусы: сколько ты сегодня в сети, настроение по времени суток, загрузку ПК сердечками и прочее.

Сделал для себя. Готовые варианты либо не умели нормально показывать обложки (API Яндекса у меня отвечал 451), либо статус пропадал при каждом переключении трека. Выкладываю, вдруг кому-то пригодится.

Работает только на Windows.

## Как это устроено

Трек читается из системных медиа-контролов Windows (SMTC), так что токены Яндекса не нужны. Подходит и приложение, и веб-версия, главное, чтобы музыка появлялась в системной плашке управления воспроизведением.

Обложку скрипт ищет сначала в Deezer, потом в iTunes. Если нигде нет, берёт картинку прямо из плеера и заливает на твой Discord-вебхук, потому что в статусе Discord принимает только ссылки. Если не нашлось совсем, ставится запасная картинка.

Пока играет музыка, показывается трек с прогресс-баром. Если поставить на паузу или переключить трек, статус не пропадает: через несколько секунд он возвращается к обычному и раз в минуту меняет экран. Экраны такие:

- твоя декоративная строка с таймером «В онлайне на протяжении:»
- статистика дня (сколько в сети, сколько треков и музыки)
- трек дня и артист недели
- сколько дней подряд ты на связи
- настроение по времени суток
- нагрузка ПК в виде сердечек
- случайная фраза из твоего списка

Статистика считается локально и лежит в `rpc_stats.json`.

## Что нужно

Windows 10 или 11, Python 3.10+ и обычный десктопный Discord (в браузерной версии Rich Presence не работает).

## Установка

Клонируй репозиторий и поставь зависимости:

```
git clone https://github.com/Wasyliy/yandex-music-discord-rpc.git
cd yandex-music-discord-rpc
pip install -r requirements.txt
```

Теперь нужно создать приложение в [Discord Developer Portal](https://discord.com/developers/applications): New Application, потом скопировать Application ID на странице General Information. Дальше открой Rich Presence → Art Assets и загрузи любую квадратную картинку (лучше 1024×1024, минимум 512×512) с ключом `cover`. Ключ потом не поменять, только удалить и загрузить заново. Discord подхватывает новые ассеты не сразу, иногда помогает перезапуск клиента.

Вебхук нужен для обложек, которых нет в Deezer и iTunes. Это необязательно, но с ним обложки находятся почти всегда. Создай приватный канал, где кроме тебя никого нет: Настройки канала → Интеграции → Вебхуки → Новый вебхук → Копировать URL. Ссылку никому не показывай и не коммить: через неё можно писать в твой канал.

Дальше скопируй пример конфига:

```
copy config.example.json config.json
```

Открой `config.json` и впиши `client_id`, остальное по желанию. Этот файл в `.gitignore`, в репозиторий он не попадёт.

Запуск:

```
python yandex_rpc.py
```

Включи трек в Яндекс Музыке, статус появится через несколько секунд.

## Автозапуск

```
powershell -ExecutionPolicy Bypass -File .\install_autostart.ps1
```

Скрипт кладёт ярлык в папку автозагрузки, и `yandex_rpc.py` запускается при входе в Windows через `pythonw.exe`, без окна. Discord при этом можно запустить позже: скрипт сам дождётся его и подключится. Убрать автозапуск можно так же, с флагом `-Remove`.

Остановить скрипт можно в диспетчере задач, процесс `pythonw.exe` во вкладке «Подробности». Если что-то пошло не так, смотри `rpc.log` рядом со скриптом.

## Настройки

Всё лежит в `config.json`, пример со всеми ключами есть в `config.example.json`. Самое нужное:

- `client_id`: Application ID, без него ничего не заработает
- `webhook_url`: ссылка вебхука для обложек из плеера
- `github_url` и `button_label`: кнопка в статусе, если `github_url` пустой, кнопки не будет
- `app_name`: название, которое показывается в обычном статусе («Играет в ...»)
- `source_hints`: по каким словам в имени приложения искать плеер. Для браузера можно добавить `chrome` или `msedge`, но тогда в статус может попасть и YouTube
- `idle_decor`, `cute_lines`, `moods`: твои тексты для обычных экранов
- `rotate_every`: как часто менять экран (в секундах)

Остальное это тайминги, их обычно трогать не нужно.

## Если не работает

Статуса нет вообще. Проверь, что Discord десктопный и запущен, и что в его настройках включён показ статуса активности. Потом загляни в консоль или `rpc.log`.

Вместо обложки вопросительный знак или иконка приложения. Скорее всего, в Developer Portal нет ассета `cover`, либо трек нигде не нашёлся. В консоли в таком случае будет строка `cover: cover`. Добавь `webhook_url`, и обложка начнёт браться из плеера.

Трек не определяется. Проверь, что музыка реально играет и видна в плашке управления воспроизведением в Windows, и посмотри `source_hints`.

## Ограничения

У одного приложения в Discord может быть только одна активность. Поэтому, пока играет музыка, таймер и обычные экраны не видны, они возвращаются после паузы. Кнопки в своём профиле ты не увидишь, их видят только другие люди. Ещё Яндекс обновляет позицию трека не каждую секунду, так что сразу после смены трека прогресс-бар может один раз подстроиться.

## Про приватность

Название трека и артист отправляются в Deezer и iTunes, чтобы найти обложку. Обложки из плеера уходят на твой вебхук. Всё остальное, включая статистику, остаётся у тебя на компьютере.

Проект неофициальный и никак не связан с Яндексом, Discord, Deezer или Apple.
