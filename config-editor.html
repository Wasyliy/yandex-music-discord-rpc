Конструктор статуса ♡

Меняй тексты и настройки здесь, не трогая код. Сохрани файл рядом со скриптом, и статус обновится сам.

В этом браузере файл скачивается, а не перезаписывается. Положи скачанный config.json рядом с yandex_rpc.py. В Chrome и Edge сохранение идёт прямо в файл.

Основное ✿

Без Application ID скрипт не запустится. Остальное по желанию.

Discord Developer Portal → твоё приложение → General Information → Application ID.

Необязательно. Через него скрипт заливает обложки, которых нет в Deezer и iTunes. Ссылка остаётся в этом файле и в твоём браузере, никуда не отправляется. Не выкладывай её на GitHub.

Показывается как «Играет в …».

Оставь ссылку пустой, и кнопки не будет. Свою кнопку ты в собственном профиле не видишь, её показывает только другим.

Слова из названия приложения с музыкой. Для Яндекс Музыки хватит «yandex». Если слушаешь в браузере, добавь его название, но тогда в статус может попасть и видео.

Ключ картинки из Developer Portal → Rich Presence → Art Assets. Показывается, когда обложку найти не удалось.
